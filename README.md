# LogSec

Supervision de securite pour les postes Windows d'une petite entreprise.

> Permettre au responsable d'une PME, sans etre informaticien, de savoir en
> permanence dans quel etat sont ses ordinateurs, et d'etre prevenu le jour ou
> quelque chose de grave commence.

Voir `docs/01-cadrage.md` pour le perimetre et la feuille de route.

## Demarrage rapide

```
py agent/collecteur.py
```
